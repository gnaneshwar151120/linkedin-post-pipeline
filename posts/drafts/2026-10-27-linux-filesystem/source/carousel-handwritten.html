reading ls -l

-rwxr-xr-x joe joe script.sh
type · user · group · everyone else

on a FILE

r = read it
w = change it
x = run it

on a DIR

r = list names
w = add / delete
x = enter (cd)
deleting a file needs the folder's w + x,
not the file's own w!

the numbers r=4 w=2 x=1, add them up

755rwxr-xr-x scripts, dirs
644rw-r--r-- normal files
640rw-r----- configs w/ secrets
chmod u+x script.sh · chown joe:joe f
NGINX 403? check for x on every folder in the path.

umask takes bits away from 666 / 777

umask 002file 664 · dir 775
umask 022file 644 · dir 755
easy to get wrong: 002 → 644? it's 664.

special bits

rwsr-xr-xsetUID: runs as owner (passwd)
rwxrwxrwtsticky: delete only your own (/tmp)

⚠ traps

chmod -R 644 dir
→ strips x, nobody can cd in. use u=rwX,go=rX
cp -r vs cp -a
→ only -a keeps owner, timestamps + exact modes
rm -rf
→ never asks. read the path twice.
